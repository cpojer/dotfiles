# `cpojer/dotfiles`

Check out [The Perfect Development Environment](https://cpojer.net/posts/the-perfect-development-environment).

## KeyBindings

`./macos/setup` links `KeyBindings/DefaultKeyBinding.dict` into `~/Library/KeyBindings` to avoid alt-space spitting out non-breaking spaces when using German or other keyboard layouts.

## Install

- `./setup`
